# 스마트 도서관 대출관리 베타

소프트웨어 시스템 설계 Checkpoint 4 / 이유민 / 233007

## 실행
```text
java -jar ssd_ip_cp4_2026f_233007_app.jar
```

첫 실행은 빈 데이터로 시작합니다. 관리자 시연에서 회원과 도서를 등록하세요.
기본 저장 위치는 사용자 홈의 `.smart-library-beta/library.xml`입니다.
기존 데이터는 프로그램 종료 후에도 유지됩니다. 파일은 동시에 한 프로그램에서만 사용하세요.

학습용 가상 데이터로 실행하려면 별도 데이터 파일을 사용합니다.

```text
java -jar ssd_ip_cp4_2026f_233007_app.jar --demo --data demo-library.xml
```

`--demo`는 지정 파일이 없을 때만 가상 데이터를 생성합니다. 이미 있는 파일을 덮어쓰지 않습니다.
실행 중인 프로그램을 모두 종료한 뒤 파일을 복사하면 백업할 수 있습니다.

## 빌드와 검사

Windows PowerShell에서 JDK 경로를 지정합니다. JDK 17 이상이 필요합니다.

```powershell
.\build.ps1 -JdkHome 'C:\path\to\jdk'
```

결과: `dist/ssd_ip_cp4_2026f_233007_app.jar`, `api_manual/index.html`.
테스트는 임시 데이터 파일만 사용하며 실제 사용자 데이터를 수정하지 않습니다.
외부 Java 라이브러리나 인터넷 연결 없이 빌드 가능합니다.

## 베타 범위

- 도서와 회원 등록, 수정, 삭제, 검색. 대출 이력이 있는 자료의 삭제는 금지합니다.
- 대출 기간 14일. 예정일 이전에 예약자가 없으면 1회 7일 연장합니다.
- 정시 반납 5회/10회마다 한도 3/5/7권. 연체 반납은 횟수를 0으로 초기화합니다.
- 미반납 연체 또는 이용 정지 중이면 대출과 예약을 거부합니다.
- 연체 반납일부터 연체일수만큼 정지하며 종료일 당일부터 이용할 수 있습니다.
- 여러 제재가 겹치면 더 늦은 종료일을 적용합니다. 이미 대출한 도서는 강제 회수하지 않습니다.
- 도서별 FIFO 예약, 중복/본인 대출 예약 차단, 예약 취소, 3일 우선 보관.
- 보관 종료일에 다음 순번으로 넘어갑니다. 제재 중인 예약자는 우선권 배정에서 제외합니다.
- 인기 도서/다독 회원 순위는 전체 대출 이력 횟수로 집계합니다.
- 도서 분실 표시는 대출/예약이 없는 소장본만 가능합니다. 분실 배상 업무는 미구현입니다.

## 시연 순서

1. `--demo --data demo-library.xml`로 시작합니다.
2. 회원 M001의 B001을 반납합니다. 정시 반납 5회와 한도 5권을 확인합니다.
3. 관리자 시연으로 바꿔 M002의 B002를 반납합니다. 연체 3일과 한도 3권을 확인합니다.
4. M003에게 B002가 우선 보관되는지 예약 화면에서 확인합니다.
5. 회원 M003으로 B002를 대출하고 프로그램을 재실행해 저장 결과를 확인합니다.
6. Javadoc의 `library/LibraryService.html`에서 메서드 설명을 확인합니다.

## 제한 사항

역할 선택은 수업 시연용입니다. 비밀번호 인증, 서버, 동시 사용자 제어, 실제 개인정보 보호 기능은 구현하지 않았습니다.
보관 기한은 실행 시/업무 처리 시/60초 화면 갱신 시 정리합니다. 종료 중에는 백그라운드 알림이 없습니다.
이 베타는 한 PC의 단일 실행을 대상으로 합니다.
